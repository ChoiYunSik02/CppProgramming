```cpp
#include <iostream>
```

```cpp
using namespace std;
```
> `std::` 접두어 없이 표준 라이브러리를 사용할 수 있도록 선언한다.

### (1) 함수 중복(오버로딩) 버전

```cpp
void printMatrix() {
```
> **매개변수 없는** `printMatrix` — 2×2 행렬에 `*` 문자를 고정 출력한다.  
> 컴파일러는 인수가 0개일 때 이 함수를 선택한다.

```cpp
    for (int i = 0; i < 2; i++) {
```
> 행(row) 반복 — `0, 1` 총 2회. 행 수가 2로 고정되어 있다.

```cpp
        for (int j = 0; j < 2; j++)
```
> 열(col) 반복 — `0, 1` 총 2회. 열 수가 2로 고정되어 있다.

```cpp
            cout << '*';
```
> `*` 문자를 출력한다. 문자가 고정값이다.

```cpp
        cout << endl;
```
> 한 행이 끝나면 줄바꿈한다.

```cpp
}
```
> 인수 없는 `printMatrix()` 함수 끝.

---

```cpp
void printMatrix(int r, int c) {
```
> **행(r)과 열(c)을 인수로 받는** `printMatrix` — 문자는 `*` 로 고정.  
> 컴파일러는 인수가 `(int, int)` 2개일 때 이 함수를 선택한다.

```cpp
    for (int i = 0; i < r; i++) {
```
> 행 반복 — `0` 부터 `r-1` 까지, 총 `r` 회 반복.

```cpp
        for (int j = 0; j < c; j++)
```
> 열 반복 — `0` 부터 `c-1` 까지, 총 `c` 회 반복.

```cpp
            cout << '*';
```
> `*` 문자를 출력한다.

```cpp
        cout << endl;
```
> 한 행이 끝나면 줄바꿈한다.

```cpp
}
```
> `(int, int)` 버전 `printMatrix` 함수 끝.

---

```cpp
void printMatrix(int r, int c, char ch) {
```
> **행(r), 열(c), 출력 문자(ch)를 모두 인수로 받는** `printMatrix`.  
> 컴파일러는 인수가 `(int, int, char)` 3개일 때 이 함수를 선택한다.

```cpp
    for (int i = 0; i < r; i++) {
```
> 행 반복 — `0` 부터 `r-1` 까지.

```cpp
        for (int j = 0; j < c; j++)
```
> 열 반복 — `0` 부터 `c-1` 까지.

```cpp
            cout << ch;
```
> 매개변수로 전달받은 문자 `ch` 를 출력한다. (고정값 `*` 가 아님)

```cpp
        cout << endl;
```
> 한 행이 끝나면 줄바꿈한다.

```cpp
}
```
> `(int, int, char)` 버전 `printMatrix` 함수 끝.

---

### (2) 디폴트 매개변수 버전 — 함수 하나로 동일 동작

```cpp
void printMatrix(int r = 2, int c = 2, char ch = '*') {
```
> 디폴트 매개변수를 사용하여 **함수 1개**로 3가지 호출 형태를 모두 처리한다.
>
> | 호출 형태 | r | c | ch | 설명 |
> |-----------|---|---|----|------|
> | `printMatrix()` | 2 | 2 | `*` | 셋 다 디폴트값 사용 |
> | `printMatrix(1, 10)` | 1 | 10 | `*` | ch만 디폴트값 사용 |
> | `printMatrix(2, 5, 'a')` | 2 | 5 | `a` | 셋 다 직접 전달 |
>
> 디폴트값은 반드시 **오른쪽 매개변수부터** 지정해야 한다.  
> `(int r = 2, int c, char ch = '*')` 처럼 중간만 생략하면 컴파일 오류.

```cpp
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++)
            cout << ch;
        cout << endl;
    }
}
```
> 오버로딩 버전과 동일한 이중 반복문 구조이다.

---

```cpp
int main() {
```
> 프로그램 실행의 시작점.

```cpp
    printMatrix();
```
> 인수 없음 → `void printMatrix()` 호출 (오버로딩) 또는 `r=2, c=2, ch='*'` (디폴트).  
> 2×2 행렬에 `*` 출력.

```cpp
    printMatrix(2, 5, 'a');
```
> 인수 3개 `(int, int, char)` → `void printMatrix(int, int, char)` 호출.  
> 2×5 행렬에 `a` 출력.

```cpp
    printMatrix(1, 10);
```
> 인수 2개 `(int, int)` → `void printMatrix(int, int)` 호출.  
> 1×10 행렬에 `*` 출력.

```cpp
    return 0;
```
> `main()` 함수가 정상 종료됨을 운영체제에 알린다.

```cpp
}
```
> `main()` 함수 끝.

## 📝 핵심 정리

| 호출 | 선택되는 함수(오버로딩) | r | c | ch |
|------|----------------------|---|---|----|
| `printMatrix()` | `printMatrix()` | 2 | 2 | `*` |
| `printMatrix(1, 10)` | `printMatrix(int, int)` | 1 | 10 | `*` |
| `printMatrix(2, 5, 'a')` | `printMatrix(int, int, char)` | 2 | 5 | `a` |

- **함수 중복(오버로딩)** : 매개변수 개수나 타입이 다른 동일 이름의 함수를 여러 개 작성.
- **디폴트 매개변수** : 인수를 생략했을 때 사용할 기본값을 함수 선언에 지정 → 오버로딩보다 코드가 간결.
- 두 방법을 **동시에 사용하면 모호성(ambiguity) 오류**가 발생할 수 있으니 하나만 선택한다.
