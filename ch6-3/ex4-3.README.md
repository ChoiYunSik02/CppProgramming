## 📄 소스코드 (줄별 설명)

```cpp
#include <iostream>
```
> `cout`, `endl` 등 입출력 기능을 사용하기 위한 헤더 파일을 포함한다.

```cpp
using namespace std;
```
> `std::` 접두어 없이 표준 라이브러리를 사용할 수 있도록 선언한다.

---

```cpp
class Vector {
```
> `Vector` 클래스 선언 시작. 내부에 동적 할당 배열을 가지는 클래스다.

```cpp
    int* mem;
```
> `int` 배열을 가리키는 **포인터** 멤버 변수.  
> 생성자에서 `new` 로 힙(heap) 메모리에 배열을 할당하고, 그 시작 주소를 저장한다.

```cpp
    int size;
```
> 동적으로 할당된 배열의 **원소 개수**를 저장하는 멤버 변수.

```cpp
public:
```
> 이하 생성자, 소멸자, `show()` 함수는 외부에서 호출 가능.

---

### (1) 생성자 오버로딩 버전

```cpp
    Vector() {
```
> **인수 없는 기본 생성자** — `Vector x;` 처럼 인수 없이 객체를 생성할 때 호출된다.  
> 크기 5, 초기값 0 으로 고정되어 있다.

```cpp
        size = 5;
```
> 배열 크기를 `5` 로 설정한다.

```cpp
        mem = new int[size];
```
> 힙 메모리에 `int` 형 원소 5개짜리 배열을 **동적 할당**한다.  
> 할당된 배열의 시작 주소가 포인터 `mem` 에 저장된다.

```cpp
        for (int i = 0; i < size; i++)
```
> 인덱스 `0` 부터 `size-1` 까지 배열 전체를 순회한다.

```cpp
            mem[i] = 0;
```
> 배열의 모든 원소를 `0` 으로 초기화한다.

```cpp
    }
```
> 기본 생성자 끝. 생성 후 메모리 구조: `mem → [0][0][0][0][0]`, `size = 5`

---

```cpp
    Vector(int size, int initVal) {
```
> **인수 2개를 받는 생성자** — `Vector y(10, 8);` 처럼 크기와 초기값을 직접 지정할 때 호출된다.

```cpp
        this->size = size;
```
> `this->size` : **멤버 변수** `size`.  
> `size` (오른쪽) : **매개변수** `size`.  
> 이름이 같아서 `this->` 를 붙여 멤버 변수임을 명시적으로 구분한다.

```cpp
        mem = new int[size];
```
> 힙 메모리에 `int` 형 원소 `size` 개짜리 배열을 **동적 할당**한다.

```cpp
        for (int i = 0; i < size; i++)
```
> 인덱스 `0` 부터 `size-1` 까지 배열 전체를 순회한다.

```cpp
            mem[i] = initVal;
```
> 배열의 모든 원소를 매개변수로 받은 `initVal` 값으로 초기화한다.

```cpp
    }
```
> 2인수 생성자 끝. `Vector y(10, 8)` 생성 후: `mem → [8][8]...[8]` (10개), `size = 10`

---

```cpp
    ~Vector() {
```
> **소멸자** — `Vector` 객체가 소멸될 때 자동으로 호출된다.

```cpp
        delete[] mem;
```
> `new[]` 로 할당한 배열 메모리를 **해제**한다.  
> 이 코드가 없으면 객체가 소멸돼도 힙 메모리가 남아 **메모리 누수(memory leak)** 가 발생한다.  
> 반드시 `new[]` 에는 `delete[]` 로 해제해야 한다.

```cpp
    }
```
> 소멸자 끝.

### (1) show() 오버로딩 버전

```cpp
    void show() {
```
> **인수 없는** `show()` — 배열의 **모든 원소**를 출력한다.  
> 컴파일러는 `x.show()` 처럼 인수 없이 호출될 때 이 함수를 선택한다.

```cpp
        for (int i = 0; i < size; i++)
```
> 인덱스 `0` 부터 `size-1` 까지 배열 **전체**를 순회한다.

```cpp
            cout << mem[i] << " ";
```
> 각 원소를 공백과 함께 출력한다.

```cpp
        cout << endl;
```
> 모든 원소 출력 후 줄바꿈한다.

```cpp
    }
```
> 인수 없는 `show()` 함수 끝.

---

```cpp
    void show(int n) {
```
> **인수 1개를 받는** `show(int n)` — 배열의 **앞 n개 원소만** 출력한다.  
> 컴파일러는 `y.show(3)` 처럼 `int` 인수 1개로 호출될 때 이 함수를 선택한다.

```cpp
        for (int i = 0; i < n; i++)
```
> 인덱스 `0` 부터 `n-1` 까지만 순회한다. 전체가 아닌 **앞 n개**만 출력한다.

```cpp
            cout << mem[i] << " ";
```
> 각 원소를 공백과 함께 출력한다.

```cpp
        cout << endl;
```
> `n` 개 출력 후 줄바꿈한다.

```cpp
    }
```
> `show(int)` 함수 끝.

### (2) 디폴트 매개변수 버전

```cpp
    Vector(int size = 5, int initVal = 0) {
```
> 생성자 1개로 `Vector()`, `Vector(10, 8)` 두 호출 모두 처리한다.
>
> | 호출 | size | initVal |
> |------|------|---------|
> | `Vector x;` | 5 (디폴트) | 0 (디폴트) |
> | `Vector y(10, 8);` | 10 | 8 |

```cpp
    void show(int n = -1) {
```
> `n = -1` 을 "전체 출력" 의 신호로 사용한다.  
> `show()` 호출 시 `n = -1` → 전체 출력, `show(3)` 호출 시 `n = 3` → 앞 3개 출력.

```cpp
        int count = (n == -1) ? size : n;
```
> 삼항 연산자 — `n` 이 `-1` 이면 `count = size` (전체), 아니면 `count = n` (앞 n개).

---

```cpp
int main() {
```
> 프로그램 실행의 시작점.

```cpp
    Vector x;
```
> 인수 없음 → `Vector()` 기본 생성자 호출. `size=5`, `mem=[0,0,0,0,0]`.

```cpp
    Vector y(10, 8);
```
> 인수 2개 → `Vector(int, int)` 생성자 호출. `size=10`, `mem=[8,8,...,8]` (10개).

```cpp
    x.show();
```
> 인수 없음 → `void show()` 호출. `x` 의 모든 원소 출력 → `0 0 0 0 0`

```cpp
    y.show();
```
> 인수 없음 → `void show()` 호출. `y` 의 모든 원소 출력 → `8 8 8 8 8 8 8 8 8 8`

```cpp
    y.show(3);
```
> 인수 1개 `(int)` → `void show(int)` 호출. `y` 의 앞 3개만 출력 → `8 8 8`

```cpp
    return 0;
```
> `main()` 종료. `x`, `y` 소멸자 자동 호출 → `delete[] mem` 실행.

```cpp
}
```
> `main()` 함수 끝.

## 📝 핵심 정리

| 호출 | 선택되는 함수 | 동작 |
|------|-------------|------|
| `Vector x;` | `Vector()` | size=5, 전체 0 |
| `Vector y(10, 8);` | `Vector(int, int)` | size=10, 전체 8 |
| `x.show()` | `show()` | 전체 원소 출력 |
| `y.show(3)` | `show(int)` | 앞 3개만 출력 |

- `int* mem; mem = new int[size];` — 힙에 배열을 동적 할당하고 포인터로 관리한다.
- `this->size = size;` — 멤버 변수와 매개변수 이름이 같을 때 `this->` 로 구분한다.
- `delete[] mem;` — `new[]` 로 할당한 배열은 반드시 `delete[]` 로 해제한다.
- **생성자 오버로딩**: 인수 개수가 다른 동일 이름 생성자를 여러 개 작성한다.
- **디폴트 매개변수**: 인수를 생략했을 때 사용할 기본값을 지정하여 함수 1개로 줄인다.
