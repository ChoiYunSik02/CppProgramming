### (1) 함수 중복(오버로딩) 버전

```cpp
bool equals(string x, string y) {
```
> **매개변수 2개** — 두 문자열 `x`, `y` 전체를 비교하는 함수.  
> 컴파일러는 인수가 `(string, string)` 일 때 이 함수를 선택한다.

```cpp
    return (x == y);
```
> `string` 끼리 `==` 연산으로 문자 하나하나를 비교한다.  
> 두 문자열이 완전히 같으면 `true`, 하나라도 다르면 `false` 를 반환한다.  
> `"Prof. Hwang" == "Prof. Kim"` → `false`

```cpp
}
```
> 전체 비교 버전 `equals` 함수 끝.

---

```cpp
bool equals(string x, string y, int n) {
```
> **매개변수 3개** — 두 문자열 `x`, `y` 의 앞 `n` 글자만 비교하는 함수.  
> 컴파일러는 인수가 `(string, string, int)` 일 때 이 함수를 선택한다.

```cpp
    return (x.substr(0, n) == y.substr(0, n));
```
> `substr(시작위치, 길이)` : 문자열의 일부를 잘라낸 새 `string` 을 반환한다.
>
> | 호출 | 결과 |
> |------|------|
> | `"Prof. Hwang".substr(0, 3)` | `"Pro"` |
> | `"Prof. Kim".substr(0, 3)` | `"Pro"` |
>
> `"Pro" == "Pro"` → `true`

```cpp
}
```
> 앞 `n` 글자 비교 버전 `equals` 함수 끝.

---

```cpp
bool equals(string x, string y, int n, string z) {
```
> **매개변수 4개** — 세 문자열 `x`, `y`, `z` 의 앞 `n` 글자를 모두 비교하는 함수.  
> 컴파일러는 인수가 `(string, string, int, string)` 일 때 이 함수를 선택한다.

```cpp
    return (x.substr(0, n) == y.substr(0, n)) &&
```
> `x` 의 앞 `n` 글자와 `y` 의 앞 `n` 글자가 같은지 비교한다.  
> `&&` : 두 조건이 **모두** `true` 여야 전체가 `true`.

```cpp
           (y.substr(0, n) == z.substr(0, n));
```
> `y` 의 앞 `n` 글자와 `z` 의 앞 `n` 글자가 같은지 추가 비교한다.  
> n=5 일 때: `"Prof." == "Prof."` && `"Prof." == "Prof."` → `true`

```cpp
}
```
> 세 문자열 비교 버전 `equals` 함수 끝.

---

### (2) 디폴트 매개변수 버전 — 함수 하나로 동일 동작

```cpp
bool equals(string x, string y, int n = 0, string z = "") {
```
> 힌트에서 제시된 시그니처대로 `n = 0`, `z = ""` 을 디폴트값으로 설정한다.
>
> | 호출 | n | z | 실행 경로 |
> |------|---|---|----------|
> | `equals(x, y)` | 0 | `""` | 전체 비교 |
> | `equals(x, y, 3)` | 3 | `""` | 앞 3글자 비교 |
> | `equals(x, y, 5, z)` | 5 | `"Prof. Lee"` | 세 문자열 앞 5글자 비교 |

```cpp
    if (n == 0) return (x == y);
```
> `n` 이 `0` 이면 전체 비교 모드 — 두 문자열을 통째로 비교한다.

```cpp
    if (z == "") return (x.substr(0, n) == y.substr(0, n));
```
> `z` 가 빈 문자열이면 두 문자열 앞 `n` 글자만 비교한다.

```cpp
    return (x.substr(0, n) == y.substr(0, n)) && (y.substr(0, n) == z.substr(0, n));
```
> `z` 가 있으면 세 문자열 앞 `n` 글자를 모두 비교한다.

---

```cpp
int main() {
```
> 프로그램 실행의 시작점.

```cpp
    string x = "Prof. Hwang";
```
> 문자열 변수 `x` 를 `"Prof. Hwang"` 으로 초기화한다.

```cpp
    string y = "Prof. Kim";
```
> 문자열 변수 `y` 를 `"Prof. Kim"` 으로 초기화한다.

```cpp
    string z = "Prof. Lee";
```
> 문자열 변수 `z` 를 `"Prof. Lee"` 로 초기화한다.

```cpp
    if (equals(x, y)) cout << "같음" << endl;
```
> 인수 2개 → `bool equals(string, string)` 호출.  
> `"Prof. Hwang" == "Prof. Kim"` → `false` → `if` 블록 실행 안 됨 → 아무것도 출력 안 됨.

```cpp
    if (equals(x, y, 3)) cout << "앞 3글자 같음" << endl;
```
> 인수 3개 → `bool equals(string, string, int)` 호출.  
> `x.substr(0,3)="Pro"`, `y.substr(0,3)="Pro"` → `true` → **`앞 3글자 같음`** 출력.

```cpp
    if (equals(x, y, 5, z)) cout << "앞 5글자 같음" << endl;
```
> 인수 4개 → `bool equals(string, string, int, string)` 호출.  
> `"Prof." == "Prof."` && `"Prof." == "Prof."` → `true` → **`앞 5글자 같음`** 출력.

```cpp
    return 0;
```
> `main()` 함수가 정상 종료됨을 운영체제에 알린다.

```cpp
}
```
> `main()` 함수 끝.

## 📝 핵심 정리

| 호출 | 선택되는 함수(오버로딩) | 비교 내용 | 결과 |
|------|----------------------|----------|------|
| `equals(x, y)` | `equals(string, string)` | 전체 문자열 | `false` |
| `equals(x, y, 3)` | `equals(string, string, int)` | 앞 3글자 `"Pro"` | `true` |
| `equals(x, y, 5, z)` | `equals(string, string, int, string)` | 앞 5글자 `"Prof."` | `true` |

- `string::substr(시작, 길이)` : 문자열의 일부를 잘라낸 **새 string** 으로 반환한다.
- `string` 끼리 `==` 연산이 가능하다 — 내부적으로 문자 하나하나를 비교한다.
- 디폴트 매개변수 버전에서 `n = 0` 을 "전체 비교" 의 신호로 활용하는 것이 핵심 아이디어다.
