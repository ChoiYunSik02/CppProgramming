# ch7-3 실습과제1 – 멤버 함수로 구현한 연산자 중복

`Complex` 클래스에 전위 `++`, 후위 `--` 연산자를 **멤버 함수**로 작성

---

## 전체 코드 및 설명

```cpp
#include <iostream>
using namespace std;
```
> 표준 입출력 헤더를 포함하고, `std::` 접두사 없이 사용하도록 선언한다.

```cpp
class Complex {
```
> 복소수를 표현하는 `Complex` 클래스를 선언한다.

```cpp
	int real;
```
> 복소수의 실수부를 저장하는 `private` 멤버 변수.

```cpp
	int img;
```
> 복소수의 허수부를 저장하는 `private` 멤버 변수. 음수 값 그대로 저장한다 (예: `x(2, -3)` 이면 `img = -3`).

```cpp
public:
```
> 이하 멤버들은 클래스 외부에서 접근 가능하다.

```cpp
	Complex(int real = 0, int img = 0) {
```
> 생성자 선언. 기본값이 0이므로 `Complex()` 처럼 인자 없이도 호출 가능하다.

```cpp
		this->real = real;
		this->img = img;
```
> 매개변수와 멤버 변수 이름이 같으므로 `this->`로 멤버 변수를 명시해서 구분하여 대입한다.

```cpp
		cout << "복소수 " << real << " - " << -img << "j" << " 생성" << endl;
```
> 객체 생성 시 복소수 형태로 출력한다. `-img`를 사용해 `img=-3`이면 `-(-3)=3`으로 출력되어 `2 - 3j 생성`이 된다.

```cpp
	}
	void show();
```
> 복소수를 출력하는 멤버 함수를 선언한다. 정의는 클래스 외부에서 한다.

```cpp
	Complex& operator++();
```
> 전위 `++` 연산자 함수를 선언한다. 매개변수가 없는 것이 전위 연산자의 특징이며, 변경된 객체 자신을 참조(`&`)로 리턴한다.

```cpp
	Complex operator--(int x);
```
> 후위 `--` 연산자 함수를 선언한다. `int` 더미 매개변수가 있는 것이 후위 연산자의 특징이며, 변경 이전 객체를 값으로 리턴한다.

```cpp
};
```
> 클래스 선언 종료.

---

```cpp
void Complex::show() {
	cout << real << " - " << -img << "j" << endl;
}
```
> 복소수를 `실수 - 허수j` 형식으로 출력한다. `-img`를 사용해 내부에 음수로 저장된 허수부를 양수로 변환해 출력한다.

---

```cpp
Complex& Complex::operator++() {
```
> 전위 `++` 연산자 함수 정의. `++x`는 컴파일러가 `x.operator++()`로 변환하여 호출한다.

```cpp
	real++;
	img++;
```
> 실수부와 허수부를 각각 1씩 증가시킨다. `img=-3`이면 `img++` 후 `-2`가 되어 출력 시 `-(-2)=2`가 된다.

```cpp
	return *this;
```
> 변경된 객체 자신의 참조를 리턴한다. 참조 리턴이므로 `++++x` 같은 연속 연산도 가능하다.

```cpp
}
```

---

```cpp
Complex Complex::operator--(int x) {
```
> 후위 `--` 연산자 함수 정의. `x--`는 컴파일러가 `x.operator--(0)`으로 변환하여 호출한다.

```cpp
	Complex tmp = *this;
```
> 감소시키기 이전의 객체 상태를 `tmp`에 복사해서 보관한다.

```cpp
	real--;
	img--;
```
> 원본 객체의 실수부와 허수부를 각각 1씩 감소시킨다.

```cpp
	return tmp;
```
> 감소하기 이전 상태인 `tmp`를 값으로 리턴한다. `tmp`는 지역 변수이므로 참조가 아닌 값으로 리턴해야 한다.

```cpp
}
```

---

```cpp
int main() {
	Complex x(2, -3);
```
> `real=2`, `img=-3`인 복소수 객체 `x`를 생성한다. 생성자에서 `복소수 2 - 3j 생성`이 출력된다.

```cpp
	++x;
```
> 전위 `++` 연산자 호출. `x.operator++()`로 변환되어 `real: 2→3`, `img: -3→-2`로 변경된다.

```cpp
	cout << "증가결과";
	x.show();
```
> `증가결과` 출력 후 `show()`로 `3 - 2j`를 출력한다. (`-(-2) = 2`)

```cpp
	x--;
```
> 후위 `--` 연산자 호출. `x.operator--(0)`으로 변환되어 `real: 3→2`, `img: -2→-3`으로 변경된다.

```cpp
	cout << "감소결과";
	x.show();
```
> `감소결과` 출력 후 변경된 `x`를 출력한다. `2 - 3j`가 출력된다. (`-(-3) = 3`)

```cpp
	return 0;
}
```
> 프로그램을 정상 종료한다.
